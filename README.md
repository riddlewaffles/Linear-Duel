# Linear Duel
### An 2 player game where you have to input mathematic functions to destroy your opponent. The game takes place on a small graphs. It supports varieties of operators. The player characters are just 2 small circles on each ends of the graph, left and right. There are also multiple big red circles as obstacles in the way so that it makes the game even more interesting. You can input any functions as long as you use operatores that the game support. 
### The game itself is inspired by Graphwar. It's a perfect game to strengthen your mathematics skills, the only limit is your imagination.
